How to Use Manual Import

  1. 1. Search Google: Open your browser, search for your target keywords (e.g., "plumber denver co")
  2. 2. View Page Source: Right-click on the page → "View Page Source" (or press Ctrl+U / Cmd+Option+U)
  3. 3. Copy HTML: Select ALL (Ctrl+A / Cmd+A) and copy the entire HTML source code
  4. 4. Paste Below: Paste the HTML into the textarea below and click "Parse & Import"

Tip: This works around Google's bot detection by using HTML from your actual browser session. The parser will extract Google Ads (PPC) and Local Service Ads (LSA) from the HTML.
