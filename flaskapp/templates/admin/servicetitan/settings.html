How to get your ServiceTitan API credentials

  1. Log in to your ServiceTitan account
  2. Navigate to Settings → Integrations → API Application Management
  3. Create a new API application or select an existing one
  4. Copy the Tenant ID, Client ID, and Client Secret
  5. Grant the application appropriate permissions (read access for customers, jobs, appointments, technicians)
  6. Paste the credentials above and save
