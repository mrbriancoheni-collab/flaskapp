1. Executive Overview

The Google Ads Tool is a full-lifecycle PPC management suite embedded inside the platform. It connects to the Google Ads REST API via GAQL, pulls live performance data, surfaces actionable recommendations, and lets users (or the automation rule engine) execute changes — all without leaving the dashboard.

Core value proposition: The tool eliminates the need to log in to the Google Ads interface for day-to-day optimizations. Synced data + AI recommendations + one-click execution means faster iteration cycles and less wasted spend.

2. System Architecture

Data Layer

  • MySQL / SQLAlchemy ORM
  • 16 ad-specific models
  • GadsStatsDaily for time-series
  • UniqueConstraints for upsert safety
  • SEOScanResult for AI agent recall

Service Layer

  • google_ads_sync.py — API pull
  • google_ads_optimizer_engine.py
  • google_ads_rule_engine.py
  • GAQL query registry (gaql_queries.py)
  • Token / OAuth management

Presentation Layer

  • Flask Blueprint: gads_bp (/account/google/ads)
  • Jinja2 + Tailwind CSS templates
  • Fetch-based AJAX (no page reloads)
  • Font Awesome icons
  • Mobile-responsive tables

Data Flow

Google Ads API (GAQL) → google_ads_search() [utils_ads.py] → sync_account() / sync_search_terms() / sync_conversions() → GadsStatsDaily / SearchTerm / ConversionAction (DB upsert) → generate_recommendations() → OptimizerRecommendation → run_rules() → AIAction → UI tabs (optimizer, campaigns, keywords, search terms, conversions, rules, A/B tests) → User action (one-click apply / auto-execute) → AdsCampaign / AdsKeyword / NegativeKeyword (DB update) → Google Ads API write (via apply_suggestion stub — v2)

Authentication Flow

OAuth 2.0 tokens stored per account via token_utils.ensure_access_token(). resolve_ads_context(account_id) returns {customer_id, login_customer_id} for MCC setups. All sync functions validate token before hitting the API and surface errors as JSON.

Current limitation: API writes (pause keyword, increase budget, etc.) apply changes locally in the DB only. The apply_suggestion() stub in google_ads_service.py needs to be wired to the Google Ads mutate API to push changes upstream.

Key Quality Score Fields (fixed)

Quality Score is a criterion attribute, not a metric. The correct GAQL path is ad_group_criterion.quality_info.quality_score (not metrics.quality_score which is invalid). Sub-score fields: .ad_relevance, .landing_page_experience, .creative_quality_score.
