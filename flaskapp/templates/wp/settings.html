403 Forbidden Error?

If you're getting 403 errors, your WordPress REST API is being blocked. Check:

  1. Security Plugins - Wordfence, Sucuri, or iThemes may block REST API. Whitelist your server's IP address.
  2. Cloudflare/WAF - Create a firewall rule to allow requests to /wp-json/*
  3. .htaccess - Ensure Authorization header passes through: RewriteCond %{HTTP:Authorization} ^(.*)
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%1]
