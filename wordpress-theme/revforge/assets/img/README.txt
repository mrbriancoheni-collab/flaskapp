Required image assets for the RevForge WordPress theme
======================================================

Place the following files in this directory before deploying:

  favicon-16.png         16×16 px favicon
  favicon-32.png         32×32 px favicon
  apple-touch-icon.png   180×180 px Apple touch icon
  site.webmanifest       Web app manifest (JSON)
  og-default.png         1200×630 px default Open Graph image
  revforge-logo.png      Full-colour logo for Schema.org Organization markup

Recommended tools:
  https://realfavicongenerator.net  — generates all sizes + webmanifest from one source image
  https://www.canva.com             — OG image design

Brand colours:
  Forge Green  #1A5C35
  Rev Amber    #D97706
  Precision Blue #1E5FA8
